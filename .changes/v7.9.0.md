## 7.9.0

- **Changed: the router rule now holds only routing.** The auto-memory
  guidance (route a durable project fact to disk, never to auto memory) moved
  from `00-router` to `30-spec`, next to "Durable decisions land in the
  spine". Both rules are injected every session, so nothing is lost. The
  router no longer lists every skill each front door hands off to: each
  internal skill's description already names the door that reaches it.
  Routing, gate authority and handoff headings are unchanged.
- **Fixed: the scaffold's changelog gate actually runs on pull requests, and
  counts only fragments changie can read.** On a private repo the gate never
  ran: the shipped checkout drops its credential, so the fetch of the base
  branch failed and the gate skipped itself on every PR. `ci-lib.sh` now
  resolves the base locally first, from the PR merge commit's first parent or
  the event's base SHA (`ci.yml` passes both), and fetches only as a last
  resort; changed-line coverage uses the same resolver. The gate also accepted
  a `.md` or `.yml` file as the fragment, which `changie merge` drops without a
  word. It now counts only `*.yaml` and fails on any other file under
  `.changes/unreleased/`, with or without a base. Two cases the running gate
  would have broken are handled: a `main` -> `prod` promotion PR needs no
  new fragment (the release cut consumed them), and a push whose prior
  commit is gone after a force-push skips both gates instead of failing.
  Reported in #707.
- **Fixed: the cross-tool `.agents/skills/` tree no longer tells an agent to
  run a URL.** Generated skills wrote helper commands as `sh "https://..."`,
  which fails on every surface, and linked shared files to GitHub's HTML
  `blob/` view, which returns a web page rather than the file. Helper commands
  now read `sh "${STEER_PLUGIN_ROOT}/scripts/..."`, and each skill that has
  one says to point `STEER_PLUGIN_ROOT` at a local steer copy, or skip the
  step and say so. Shared files link to `raw.githubusercontent.com`; a
  directory links to its `tree/` page. Reported in #721.
- **Fixed: the scaffold's CI works on an `infra` repo, and Vitest coverage
  reaches the changed-line gate.** The `infra` profile's `mise.toml` replaced
  the core one without its `ci:*` tasks, so every step of the shipped
  `ci.yml` failed with "no task found". It now carries them verbatim, and a
  test fails if `ci.yml` ever runs a task a root config does not define.
  `ci-test.sh` passed `-- --coverage` to `pnpm run test`; pnpm forwards the
  `--` literally, Vitest ignores every flag after it, no `lcov.info` was
  written and the coverage gate skipped itself on every run.
- **Fixed: skill steps that pointed at nothing, or broke when followed.**
  `roadmap` routed feature issues through `/steer:issues materialize`, which
  writes an approved intent back to `draft`; it now names only
  `/steer:tracker-sync find-or-create`. The `gh issue edit #N` examples in
  `tracker-sync` turned the rest of the command into a shell comment. Dead
  references are gone: "rule 62" and "rule 95" (hotfix, protect),
  `/steer:setup protect --check` (promote), `apply solo` (waive). Next actions
  shown to the user name `/steer:setup sync`, not the internal `/steer:sync`.
- **Fixed: four hook gates misread their input.** The write nudges and the
  version-pin gate classified the absolute file path, so every write inside a
  Claude Code worktree (under `.claude/worktrees/`) counted as spec and got no
  nudge, and a repo cloned under any `docs/` directory was exempt from the pin
  gate. Both now classify the path relative to the repo. A major-only tag such
  as `python:3` was denied as "below 3.11"; it now floats the minor, as the
  conventions say, here and in the scaffold's `ci:hygiene` scan. The
  trunk-push gate read a quoted `git -C "dir"` target with its quotes on and
  silently let the push through. The stacked-PR gate read `-B scratch` from a
  PR body as the base branch and asked for no reason.
- **Fixed: every path a command touches in the cross-tool `.agents/skills/`
  tree is now local, not just the helper itself.** A helper's template
  argument and the plugin directories `/steer-doctor` hands to `grep` and
  `find` still became GitHub URLs, so template reconciliation failed even
  with a local steer copy, and the CRLF check silently passed. They now read
  `"${STEER_PLUGIN_ROOT}/..."`.
- **Fixed: an `infra` repo can record the changelog fragment its CI gate
  asks for.** The `infra` profile's `mise.toml` wired `ci:changelog` but
  had no `changelog:new` or `changelog:merge` task and no `changie` pin, so
  the gate's failure message pointed at a task that did not exist. It now
  carries both tasks and the pin verbatim from the core config, and a test
  fails if a `ci-*.sh` script names a task a root config does not define.
